# Sales Performance Power BI Dashboard

![Dashboard Preview](Dashboard%20Preview.png)

## Project Overview

An interactive **Power BI Sales Performance Dashboard** developed to analyze sales, profit, orders, products, customers, and regional performance.

## Key KPIs & Analysis

- Total Sales and Profit
- Profit Margin %
- Average Order Value
- Sales Target vs Actual
- Regional Performance
- Category and Product Analysis
- Customer Segment Analysis
- Interactive Slicers and Filters

## Dataset

The project uses an Excel sales dataset containing order, customer, product, category, region, sales, profit, quantity, discount, and shipping information.

## Tools & Technologies

**Power BI | DAX | Power Query | Microsoft Excel**

## Project Workflow

1. Imported the Excel dataset into Power BI.
2. Cleaned and transformed data using Power Query.
3. Created DAX measures for business KPIs.
4. Designed interactive cards, charts, slicers, and a sales target gauge.
5. Built a dashboard for sales and profitability analysis.

**Data Cleaning | Data Transformation | Data Visualization | DAX | KPI Development | Business Analysis | Power BI**
